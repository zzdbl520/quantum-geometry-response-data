# Reproduction and provenance

## Verified workflow

From `multistate/`:

```bash
python -m pip install -r requirements.txt
python scripts/verify_manifest.py
python scripts/reproduce.py
```

The workflow runs two numerical verifiers and the figure scripts. It has
been executed for this release. See `verification/environment.json` for
the observed environment and the JSON reports for the numerical errors.
No PySCF installation is needed for these derived-data checks.

The verification covers:

1. Support-restricted response factorization, unitary covariance, the
   split-cluster Sylvester equation, exact finite-field projectors and aligned
   quadratic matrices, a support counterexample, and the three-state cusp.
2. C2 crossings, overlap minima, and projected-dipole maximum.
3. B2 record counts, derivative/direct ratios, original versus hybrid flags,
   and the direct-coupling model cusp.
4. Reaction pair inventories, reconstruction from D01 and the zero-field gap,
   local field-envelope margins, and retention of the reported failures.
5. Regeneration of all three current molecular figures and the SI control figure.

## Build the Supplementary Material

Run from `multistate/supporting_information/`:

```bash
pdflatex -interaction=nonstopmode -halt-on-error JCP_Supporting_Information.tex
bibtex JCP_Supporting_Information
pdflatex -interaction=nonstopmode -halt-on-error JCP_Supporting_Information.tex
pdflatex -interaction=nonstopmode -halt-on-error JCP_Supporting_Information.tex
```

The source requires LaTeX, REVTeX 4.1, graphicx, bm, booktabs, mathtools,
mhchem, xcolor, and hyperref. The legacy REVTeX and chemistry style files
distributed with the supplied author package are retained alongside the
source. `verification_table.tex` is regenerated by the Python workflow.

## Provenance and limitations

The molecular `evidence/` tree comes from the supplied author revision
archive `JCP_submission_revised.zip`. `verification/source_provenance.json`
records its SHA-256 hash, evidence count, and byte-preservation comparison.
The evidence files retain their original contents and line endings.
Older status messages, captions, and absolute server paths are historical.
They are not a substitute for the current manuscript's scope statements.

The reaction geometry NPZ was originally obtained from
[H2COMBUSTION_DATA](https://github.com/THGLab/H2COMBUSTION_DATA), channel 1,
with the source data DOI
[10.6084/m9.figshare.19601689](https://doi.org/10.6084/m9.figshare.19601689).
Its source hash is checked against `evidence/HO2/protocol_metadata.json`.

The deposit does not contain all original CASSCF checkpoints, signed-field
wavefunctions, optimization seeds, or exact production environments. Some
historical source scripts depend on these unavailable inputs. The B2
state-specific gaps are retained in derived tables, but the entire original
state-specific production workflow is not supplied. The SA2 and state-specific
reaction curves are comparison values in the distributed summary, not a full
new reproduction from all original field jobs.

Accordingly, the documented commands reproduce table analyses, figures, and
theoretical checks. They do not reproduce every molecular wavefunction from
scratch or independently reconstruct all stored many-electron overlaps.

## Figure revisions in the final materials check

The current C2 figure is generated by `scripts/plot_c2_current.py`, adapted
from the supplied `evidence/C2_figure/plot_c2_certified_final.py`. Only the
interpretive label was changed from orbital-branch bifurcation to
orbital-continuity failure; the plotted data, acceptance gates, and original
evidence are unchanged. Historical diagnosis codes remain in the provenance
metadata and are not independent proof of a mathematical bifurcation.

The manuscript uses the 13-geometry B2 figure and the reaction figure with
aligned-background, internal-mixing, and total-median labels. The archived
`figures/scheme.*` is a historical sketch, not the manuscript's Figure 1.
The manuscript source package contains a separately redrawn vector Figure 1
that states the exact-degeneracy and spectral-isolation conditions explicitly.
